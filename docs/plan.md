# خطة تنفيذ BOOKLIT App: أسبوع واحد

المرجع: `BOOKLIT_UI_Design_Developer_Guide.docx`، والتصاميم المرسلة، ووثيقة [BOOKLIT Studio](booklit-studio.md).

## التقنية

| الجزء | الاختيار | السبب |
|------|----------|-------|
| التطبيق | Expo (React Native) + Expo Router + TypeScript | تطبيق واحد لـ iOS وAndroid، ويُجرَّب فوراً على Expo Go |
| الخط | Plus Jakarta Sans | من هوية BOOKLIT |
| الأيقونات | Material Community Icons (Line) | عائلة موحدة وخفيفة |
| الذكاء الاصطناعي | Gemini `gemini-3.5-flash-lite` (نموذج رخيص) عبر `src/app/api/ask+api.ts` على EAS Hosting | المفتاح متغير `GEMINI_API_KEY` على Expo، ولا يدخل التطبيق |
| الخادم (المرحلة 2) | Supabase: Postgres + Auth + Storage + RLS | حماية المحتوى المدفوع من الخادم، ولوحة إدارة سريعة |

## ما تم (اليوم 1–2): واجهة التطبيق كاملة

- [x] **الرأس الثابت (Header):** تدرّج أزرق/بنفسجي، شعار Booklit، إشعارات مع نقطة، بحث، وتبديل الوضع الليلي.
- [x] **شريط التنقل الثابت:** كبسولة بيضاء، والقسم النشط بنفسجي على خلفية Lavender (Home, Library, Progress, Favorites, Profile).
- [x] **Home:** ترحيب باسم الطالب، بحث، بطاقة Continue Reading ترجع لآخر موضع قراءة، اختصارات المراحل، وقائمة Continue Studying.
- [x] **Library:** فلترة حسب المرحلة والنوع (مجاني/مدفوع)، بطاقات المواد، قفل صغير، ونافذة «هذه المادة مقفلة» مع زر تيليجرام وزر إغلاق.
- [x] **صفحة المادة:** الملازم والمواضيع. عمودان على الشاشات العريضة، وملازم ثم مواضيع على الهاتف. الملزمة النشطة مميزة.
- [x] **القارئ:** الجزء العلوي يختفي أثناء القراءة، شريط سفلي صغير، حفظ آخر موضع، Topic مستقل مع تنقل سابق/تالي، وجداول وصور وصناديق تعليمية.
- [x] **أزرار أسفل الموضوع:** Ministry MCQs و Instructor MCQs و Quiz Mode و **Ask AI** و Edit و Coming Soon.
- [x] **Edit:** المحتويات، البحث داخل الموضوع، حجم النص، الإشارة المرجعية، التظليل، وتعليم الموضوع كمكتمل.
- [x] **MCQs:** كل سؤال مرتبط بـ Topic. وضع تدريب مع شرح فوري، و Quiz Mode مع نتيجة ومراجعة الإجابات.
- [x] **Ask AI:** محادثة عن المادة والموضوع المفتوح أمام الطالب، بالعربي أو الإنجليزي.
- [x] **Progress:** نسبة إجمالية حقيقية، وتقدم كل مادة، وتفاصيل كل ملزمة.
- [x] **Favorites:** Booklets و Topics، إزالة، ورسالة فارغة.
- [x] **Profile:** بطاقة الطالب والإحصائيات (الملازم، الدقة، وقت الدراسة) والإعدادات كلها، و Log Out.
- [x] **الوضع الليلي**، وحفظ كل شيء على الجهاز.

## التحديث الثاني: إعادة التصميم ورفع الملفات

- [x] **أيقونات نازكة** (Lucide line icons، سُمك 1.6) بكل التطبيق.
- [x] **خطوط أصغر وأهدأ**: Plus Jakarta Sans بأوزان Light/Regular/SemiBold، وعناوين بلونين («Ready to **study today?**»).
- [x] **شيلنا الرأس الثابت**. كل شاشة صار إلها رأس بسيط داخل الصفحة.
- [x] **شريط تنقل داكن عائم قابل للسحب**: تسحب المؤشر الأبيض بين الأقسام، والألوان تتغير وفق موضع السحب، وعند الإفلات ينتقل للقسم الأقرب (مع اهتزاز خفيف على الهاتف).
- [x] **Library جديدة**: بطاقات صور موحدة، فلترة بالمرحلة، وقسم «My uploads». الصور من Gemini حسب [`image-prompts.md`](image-prompts.md).
- [x] **القارئ مثل Kindle**: صفحة واسعة، والأدوات تختفي أثناء القراءة وترجع بلمسة. ألوان صفحة Light/Sepia/Dark، وشريط سفلي صغير، وبحث بين النتائج، وتظليل، وحجم خط، وفهرس، وحفظ آخر موضع. أزرار Ministry/Instructor/Quiz Mode/Edit/Ask AI/Coming Soon أسفل كل موضوع.
- [x] **رفع ملف ← ملزمة**: PDF و Word و PowerPoint وصور ونص، بأي لغة. يحافظ على النص الأصلي، ويقسمه لمواضيع، ويكتب أسئلة لكل موضوع (`src/app/api/import+api.ts`).
- [x] Home و Ask AI و Profile بنفس أسلوب التصاميم المرفقة.

## التحديث الثالث: المحرر، سجل الأخطاء، المرحلة الأولى والثانية

- [x] **إصلاح رفع الملفات على الموبايل**: Expo fetch ما يقبل ملفات FormData بصيغة `{ uri }`، فالموبايل صار يرسل الملف base64 JSON، والسيرفر يقبل الطريقتين.
- [x] **محرر الملازم** (`/editor/[bookletId]` و `/editor/topic/[topicId]`):
  - تعديل عنوان الملزمة والمواضيع، وترتيبها، وإضافة وحذف المواضيع.
  - كتل: فقرة، عنوان، قائمة، جدول (صفوف وأعمدة)، ملاحظة (Key point/Warning/Tip)، صورة من المعرض مع وصف.
  - لكل كتلة: نقل لفوق ولجوة، تكرار، تحويل نوع، حذف، وإدراج كتلة بين أي كتلتين.
  - أدوات AI: تصحيح، تبسيط، شرح أكثر، تحويل لنقاط، ملاحظة مختصرة، ترجمة عربي ⇄ إنكليزي.
  - الأسئلة: تعديل السؤال والخيارات والإجابة الصحيحة والشرح والمصدر، وتوليد 5 أسئلة بالـ AI، وملء الأسئلة الناقصة لكل المواضيع.
  - تراجع (Undo)، وحفظ تلقائي، ومعاينة بالقارئ، وإنشاء ملزمة من الصفر.
- [x] **سجل الأخطاء** (Profile → Error log): أخطاء الرفع والـ AI والشاشات وأي انهيار، مع معلومات الجهاز، وأزرار Share و Copy و Clear.
- [x] **المرحلة الأولى والثانية** مع 3 مواد لكل مرحلة.

## التحديث الرابع: الجداول والصور

- [x] **جداول أوضح بالقارئ**: الجدول الضيق (4 أعمدة أو أقل) ينعرض بعرض الصفحة والنص ينلف داخل الخلايا. الجدول العريض يتمرر لليمين واليسار وفوقه تلميح «Swipe to see all N columns». وكل جدول بي زر **Full screen** يفتحه بشاشة كاملة تتمرر بالاتجاهين، وصف العناوين يبقى ثابت.
- [x] **إصلاح تمرير الجداول**: الجدول ما بقى داخل منطقة اللمس الطويل (التظليل) اللي جانت تمنع التمرير الجانبي.
- [x] **سحب الصور من الـ PDF**: السيرفر يطلع الصور الموجودة داخل الملف (JPEG و PNG) ويحطها بمكانها بالملزمة حسب رقم الصفحة. يتجاهل الأيقونات الصغيرة، والشعارات المتكررة، وصفحات السكانر الكاملة.
- [x] **إضافة صور بالمحرر**: من المعرض أو بالكاميرا مباشرة، وزر «Add image» سريع. والضغط على أي صورة بالقارئ يفتحها بشاشة كاملة مع تكبير.
- [x] **ثبات التحويل**: الجداول صارت تجي كاملة ويا عناوينها (جربتها 10 من 10)، ومحاولة ثانية تلقائية إذا تعثر Gemini.

## التحديث الخامس: الصلاحيات، الاستوديو، والقارئ الجديد

### الصلاحيات
| الحساب | القراءة والأسئلة والـ AI | التظليل والملاحظات والرسم | تعديل تصميم الملازم | رفع الملازم وبنك الأسئلة |
|--------|:---:|:---:|:---:|:---:|
| **Pro** | ✓ | ✓ | (مخفي) | (مخفي) |
| **Premium** | ✓ | ✓ | ✓ | (مخفي) |
| **Admin** | ✓ | ✓ | ✓ | ✓ (BOOKLIT Studio) |

- وضع الأدمن يُفتح من Profile → Account & plan برمز (حالياً `2468`، ويتغير بـ `EXPO_PUBLIC_ADMIN_CODE`).
- ⚠️ هذا قفل محلي على الجهاز بس. الحماية الحقيقية تحتاج حسابات على الخادم (المرحلة القادمة).

### BOOKLIT Studio (للأدمن)
- **ملزمة من ملف**: تختار الملف، والمادة اللي تنحط بيها، وطريقة التصميم (**AI design**: أقسام وقوائم وجداول و Exam tips وملخص Key points لكل موضوع، بدون حذف أي نص؛ أو **Original**)، وعدد الأسئلة لكل موضوع.
- **بنك الأسئلة ← المواضيع**: ترفع ملف أسئلة وزارية أو أسئلة أستاذ لأي ملزمة. الـ AI ينقل كل سؤال حرفياً، ويأخذ الجواب من مفتاح الإجابة، وإذا ما موجود يحله ويعلّمه «AI answer» حتى تراجعه، ويوزع الأسئلة على المواضيع. بعدها تراجع وتنقل وتعدل وتحذف قبل الحفظ. (الاختبار: 10/10 أجوبة صحيحة و10/10 بمواضيعها.)

### القارئ
- **تظليل جزء من الجملة**: ضغطة مطوّلة على أول كلمة، أو وضع Highlight وضغطة، وبعدها ضغطة على آخر كلمة. أربع ألوان، وملاحظة، ونسخ، وسؤال الـ AI عن الجزء المحدد.
- **ملاحظات** فوق النص (علامة ✎)، وقائمة «Notes & highlights» لكل موضوع.
- **الرسم**: قلم بأربع ألوان، وماركر، وممحاة، وتراجع، ومسح. الرسم يتحرك ويا النص ويبقى بمكانه إذا دار الجهاز.
- **إعدادات القراءة**: الصفحة (Auto/Light/Sepia/Dark)، والخط (Sans/Serif)، والحجم، وتباعد الأسطر، والهوامش.
- **التابلت**: فهرس ثابت على الجانب، ونص أعرض وأكبر، وأزرار التمارين بثلاث أعمدة.
- **الموبايل**: شريط تقدم فوق، ووقت القراءة المتبقي، وشريط أدوات مرتب.

## التشغيل محلياً

```bash
cd booklit-app
npm install
npx expo start        # امسح الـ QR بتطبيق Expo Go
```

## النشر

```bash
cd booklit-app
npx expo export --platform web && eas deploy --prod --environment production   # خادم Ask AI
eas update --channel preview --environment production -m "وصف التحديث"          # تحديث التطبيق على Expo Go
```
