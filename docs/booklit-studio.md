# BOOKLIT Studio — The Content Creation Engine

> **Create. Design. Publish.**

BOOKLIT Studio جزء أساسي من المنظومة وليس ميزة صغيرة داخل التطبيق، لأنه الأداة التي تُنتج المحتوى التعليمي الذي يُعرض ويُباع داخل BOOKLIT. يُبنى كمنتج مستقل ضمن منظومة BOOKLIT، ويرتبط بالتطبيق وبقاعدة بياناته.

**القرار الحالي:** يبدأ Studio كأداة داخلية لفريق BOOKLIT، ولا يُباع للمستخدمين في هذه المرحلة. لكن تُصمَّم بنيته بحيث يمكن تحويله لاحقاً إلى منتج مستقل.

---

## 1. الفكرة

منصة متخصصة في إنشاء الملازم والكتب التعليمية وتصميمها وإنتاجها بصورة احترافية، من غير الحاجة إلى برامج التصميم التقليدية لكل ملزمة.

يُدخل المستخدم المحتوى العلمي، وينظّمه ويقسّمه إلى مواضيع، ويضيف الصور والرسوم التوضيحية، ثم يُنتج ملزمة PDF جاهزة للنشر بهوية BOOKLIT.

**الهدف:** تحويل إعداد الملزمة من عمل يدوي طويل إلى نظام إنتاج تعليمي منظّم وقابل للتوسع.

## 2. الوظائف الأساسية

| # | الوحدة | الوصف |
|---|--------|-------|
| 1 | **Content Editor** | إدخال النصوص العلمية وتعديلها، ويدعم العناوين والفقرات والجداول والقوائم والمصطلحات الطبية |
| 2 | **Smart Layout Engine** | يحوّل المحتوى تلقائياً إلى صفحات تعليمية مرتبة، ويوزّع العناوين والفقرات والصور بذكاء |
| 3 | **Visual Learning System** | إضافة الرسوم التوضيحية والمخططات والصور الطبية والمربعات التعليمية |
| 4 | **PDF Generator** | ملفات PDF عالية الجودة فيها ترقيم صفحات وفهرس وترويسات وتذييلات |
| 5 | **Publishing System** | حفظ الملزمة، وإصدار نسخ منها، وتجهيزها للنشر داخل تطبيق BOOKLIT |

## 3. نظام التصميم الموحد (Design System)

- هوية بصرية واحدة لكل المواد.
- لون رئيسي مختلف لكل مادة دراسية.
- خطوط وأحجام ثابتة.
- قوالب صفحات موحدة.
- أماكن مرنة للصور حسب المحتوى.
- يمكن إضافة الصور بعد إصدار PDF أولي.
- بعد إضافة الصور يُعاد توزيع الصفحات وترقيمها تلقائياً.

| المادة | الثيم |
|--------|-------|
| Oral Surgery | Purple |
| Orthodontics | Blue |

تختلف المواد في اللون والعناصر التعريفية فقط. النظام التصميمي نفسه لا يتغيّر.

- **BOOKLIT Studio:** منصة فريق العمل لإنشاء المحتوى وتصميمه وإنتاجه.

## 6. الربط بين Studio والتطبيق

```
BOOKLIT STUDIO  (Content Creation & Publishing)
        │
        │  Publishing & Content Synchronization
        ▼
BOOKLIT APP     (Learning & Reading Experience)
```

عند اعتماد ملزمة داخل Studio ونشرها:

1. تُحفظ بيانات الملزمة ومواضيعها.
2. تُرفع ملفاتها وصورها إلى التخزين.
3. تُرسل بيانات المحتوى إلى قاعدة بيانات BOOKLIT.
4. تظهر الملزمة في المكتبة حسب المرحلة والمادة.
5. يفتحها الطالب ويقرؤها.
6. تظهر الأسئلة الوزارية وأسئلة الأستاذ والاختبارات المرتبطة بمواضيعها.

## 7. ملاحظة مهمة للمبرمج

Studio **ليس** محرر نصوص يضيف بعض الألوان ثم يحوّل النص إلى PDF. هو نظام حقيقي لإنتاج المحتوى التعليمي، ويحتاج بنية مستقلة وقابلة للتطوير تسمح بإضافة أدوات مستقبلية مثل:

- AI Content Structuring
- AI Diagram Generation
- Automatic MCQ Generation
- Medical Illustration Tools
- Smart Page Layout
- Version Control

هذه ميزات مستقبلية، وليست كلها شروطاً لإطلاق النسخة الأولى.
